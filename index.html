1 问题

Elfeed 数据库无法跨设备同步，导致阅读进度不一致。

2 解决方案

使用 rclone + 坚果云 WebDAV 实现双向同步。

vendor = jianguoyun
user = [YOUR_EMAIL]
pass = [YOUR_PASSWORD]
